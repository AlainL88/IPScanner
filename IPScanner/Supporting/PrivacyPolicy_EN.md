## 1. PERSONAL DATA PROCESSED

### 1.1 Data processed locally on the device (NOT transmitted)

The Application is a local network scanner: all scans are performed **entirely on the User's device**. The data collected is stored locally on the device and **is not transmitted to the Controller or to external servers**. This includes:

- IP addresses, MAC addresses, hostnames and manufacturers of the devices detected on the local network;
- Port scan results and device status information (e.g. Wake-on-LAN);
- Scan history and export data (CSV/JSON);
- Customizations made by the User: custom names, icons and the list of trusted devices (whitelist).

### 1.2 Automatically collected data (ONLY if Crashlytics is active)

The Application may integrate **Firebase Crashlytics** (Google LLC) for error and crash reporting. This integration is **optional**: it is enabled by the Controller only in builds that include the Google configuration file (`GoogleService-Info.plist`). When active, the following may be collected:

- Anonymous installation identifier (App Instance ID) — this is **NOT** the Apple IDFA advertising identifier;
- Device type and model, operating system version and application version;
- Application crash and error reports (Crashlytics).

**The Application does NOT collect:**
- Accounts, name, email or authentication data (no registration required);
- Advertising identifier (IDFA/AAID);
- Payment data (the Application is free and contains no in-app purchases);
- Precise location data;
- Web browsing or other app activity data;
- Personal content of the User (documents, photos, etc.).

### 1.3 System permissions requested

The Application may request the following permissions; each may be revoked by the User at any time through device settings:

| Permission | Purpose | Mandatory? |
|---|---|---|
| **Local Network** | Detection and scanning of devices on the network | YES (core functionality) |
| **Notifications** | Alerts for newly discovered devices | NO |

- Compliance with legal, regulatory and statutory obligations;
- Responding to legitimate requests from competent authorities.

**C. Legitimate Interest** (legal basis: Legitimate interest — Art. 6(1)(f) GDPR)

- Preventing fraud and abuse;

**D. Consent** (legal basis: Consent — Art. 6(1)(a) GDPR)
- Activation of specific system permissions (local network, notifications, etc.);

### 2.2 International Data Transfer

Only if Crashlytics is active, crash data may be transferred to countries outside the European Economic Area (EEA), in particular to the **United States of America** (Firebase servers).

The transfer is based on the **Standard Contractual Clauses (SCC)** adopted by the European Commission, incorporated into Google Firebase's Data Processing Agreement (DPA), which the Controller has accepted. A copy of the SCC is available upon request.

For residents of California (USA), the protections of the California Consumer Privacy Act (CCPA) also apply.
